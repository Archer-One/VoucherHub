# 实现范围与连接核对

整理日期：2026-11-17。基于 2026-11-10 完整测试包，同步论文工作目录截至 11 月 12 日的 Java 协议源码（含兑换及证明消息更新），保留实验实现，补齐既有 bn128 Rust/JNI 源码。
论文核对版本：VoucherHub_SP2027_files__2_.pdf，§3（第3页）、§9（第12页）、附录（第18页）。

| 连接 | 本包正式实验路径 |
|---|---|
| payer → payee | 本地 SOCKS5 9050 → Tor v3 onion:9101 → payee 的 127.0.0.1:9101；请求与响应共用连接 |
| payer → hub | 本地 19100 → 已有 SSH 转发 → hub TCP 9100 |
| payee → hub | 需要兑换/Accio channel credit 时，通过本地 19100 → SSH 转发 → hub TCP 9100 |
| 用户 → 链 | gas 目录中的独立合约交易测量；不是在线付款计时链路 |

论文用户–hub 接口为认证连接，实验段写的是 direct TCP with authenticated messages。本包原部署器使用 SSH 隧道承载 TCP，比裸 TCP 多一层传输保护和开销，不能声称网络时延与论文图完全相同。协议消息的认证范围仍由既有原型决定。

本次修正：正式 payee 只绑定回环地址；payer 在建立连接之前拒绝非 v3 onion 格式地址；原有 direct 模式仍须显式 --allow-direct-baseline true；Tor 失败抛错，不回退直连。历史 DistributedBenchmark 和 direct/adjusted 脚本保留供追溯，不作为正式入口。

## 算法索引

- common/.../protocol/VoucherHubProtocol.java：Mint、voucher transfer、split、redeem、批量操作。
- common/.../protocol/FairMint.java、Model.java：协议状态和消息对象。
- common/.../crypto/：DRSign、Sigma opening proofs、bn128 和签名/承诺支持。
- third_party/bulletproof-src/：范围证明。
- native/：bn128 Rust/JNI 密码实现，可在目标 Linux 环境编译。
- EvaluationNetworkBenchmark.java、EvaluationWire.java：三实体网络消息与计时。
- experiments/voucherhub_evaluation/：部署、单/多 payer、统计和测试。
- contracts/、gas/：原型合约及 gas 交易测量。

以上路径位于 code/未命名/ 下（native 和 experiments 除外）。

## 完整性的边界

这是此前已实现实验代码的完整整理，不表示最新论文全部形式化协议已实现。Accio 是重建的参考基准；gas 合约为测量 scaffold，不是完整生产级 T-RSUC/DRSign verifier。最新论文的完整授权、恢复、失败历史及在线可提取证明语义不能仅凭现有自测认定全部覆盖。

论文 Figure 2 为 TCP 测量加 Tor 校准增量；本包推荐入口直接测 Tor，结果必须另行标注，不能冒充论文原图数据。本包未包含 SSH 私钥、历史数据或伪造的 Tor 结果。正式运行需可达的实验节点、其私钥和已启动的 Tor；节点配置保留旧值，部署前核对。
